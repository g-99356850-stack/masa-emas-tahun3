# 🎮 Pengembaraan Masa Emas 3D — Edisi Harta Karun

**Tajuk:** الوَقْتُ كَالذَّهَبِ  
**Sasaran:** Bahasa Arab Tahun 3, SK Taman Sri Muda, Shah Alam.

Game pendidikan 3D untuk pembelajaran waktu: dunia penerokaan, 4 avatar, NPC beranimasi, 5 peti harta karun, kosa kata, kuiz, ganjaran dan sijil.

## Cara bermain
Buka `index.html` dalam pelayar moden. Di telefon gunakan kawalan sentuh, di komputer gunakan WASD.

## GitHub Pages
1. Upload semua fail daripada pakej ini ke root repositori.
2. Pergi ke **Settings → Pages**.
3. Pilih **Deploy from a branch**, **main**, **/(root)** dan klik **Save**.
4. Setelah diterbitkan, buka halaman `https://<username>.github.io/<repository>/`.

Nota: Pelaksanaan 3D dan audio memerlukan sokongan pelayar/peranti. Sesetengah fail JS luar mungkin memerlukan sambungan internet.
